# `/vectis · identity`

> *One signature, four functions.*

## The slash chrome system

The forward slash is the single ownable signature across all Vectis surfaces. It carries four distinct functions, each a different application of the same atom:

```
Logo:     /vectis
          The wordmark itself. Pairs with the open bracket lockup.

Command:  /audit  /begin  /deploy  /align
          CTAs and buttons that read as terminal commands.

Prefix:   /vectis · proposal · acme corp · 2026-05-12
          File labels, metadata, footer attribution.

Frame:    /foundation  /principles  /this-book
          In-page structural dividers and section headers.
```

Don't introduce a second signature element. The slash carries all four jobs.

## The lockup

Vectis ships with one lockup variant. The open bracket frame applies everywhere — wordmark, CTAs, hero typography. Discipline of a single chrome across all surfaces is the brand.

```
Primary lockup:    [ /vectis ]
                   Wordmark on every brand surface.
                   Used at all sizes above the minimum threshold.

CTA application:   [ /begin engagement → ]
                   Same bracket frame, slash command verb inside,
                   trailing arrow. The lockup language extends to
                   actionable surfaces without a second variant.

Prefix application: /vectis · t2 align · shua
                    No brackets. Used for labels, metadata, footers.
                    The bracket frame is reserved for the wordmark
                    and CTAs only.
```

## Construction

The primary lockup is built from three Brass elements + the wordmark in Söhne. The square-on-i is non-negotiable at primary size — it is the structural callout that makes the lockup unmistakably Vectis.

```
                ▪          ← square-on-i (brass, optical-aligned 
                              to dot height of the i)
     [   /vectis   ]
     ▲    ▲                 
     │    │                 
     │    └─ slash (brass, leading the wordmark)
     │
     └─ open brackets (brass, frame the wordmark with breathing room)

   Wordmark: Clash Grotesk Bold, Deep Ink (or Bone, inverted on dark surface)
   All structural elements (slash, square-on-i, brackets): Brass #A8896C
```

NB: the rendered brand book replaces this ASCII placeholder with proper leader-line callouts. The diagram language ships in Page 05.

## Mono labeling pattern

Partners use this pattern to append context to any Vectis artifact:

```
/vectis · [type] · [identifier] · [date]

Examples:
/vectis · proposal · shua · 2026-05-12
/vectis · t2 align · acme corp
/vectis · brand book v1 · page 02
/vectis · audit · q3 plan
/vectis · sow · stage 1 · v3
```

Set in IBM Plex Mono. Brass slash, Deep Ink (or Bone) text. Lowercase. Middots `·` between segments, never bullets or pipes. This pattern lives on every footer, every file metadata block, every artifact attribution. It is how partners make any deliverable read as Vectis without needing the full lockup.

## Clear space + minimum sizes

```
Clear space:        = height of the slash
                      no other element enters this zone

Primary lockup:     ≥ 32px / 24pt
                      [ /vectis ] with square-on-i — full lockup

Reduced lockup:     16–31px / 12–23pt
                      /vectis with square-on-i — brackets drop,
                      structural callout stays

Minimum lockup:     8–15px / 6–11pt
                      /vectis only — square also drops, slash carries

Below 8px:          standalone slash mark as favicon / chip
```

The square-on-i is the signature, not the brackets. Brackets are frame; the square-on-i is what makes the lockup unmistakably Vectis. When sizes force a choice, drop the frame before dropping the signature.

## Don'ts

```
Never:
─ Tilt, rotate, or distort the lockup
─ Render the slash or square-on-i in any color other than Brass
─ Use parentheses ( ), square brackets [ ], curly braces { }, or quotes
  in place of the open bracket frame
─ Overlap content with the bracket frame
─ Add drop shadows, gradients, glows, outer strokes, or 3D effects
─ Pluralize, abbreviate, or modify "vectis" inside the lockup
─ Apply the bracket frame to anything that isn't the wordmark or a CTA
─ Use the lockup as decoration (it is structural, not ornamental)
```
