# Vectis Project — Knowledge Index

The Vectis project knowledge is organized into three layers: the spine (working docs that evolve), the research foundation (point-in-time scans with strategic recommendations), and operator context. Reach for files based on the conversation, not by default.

## The spine — working docs

- **`vectis.md`** — long version, partner-facing. The full doc with positioning, verticals, sales motion, brand direction, risks, workstreams, and open questions with owners. Use this when you need full context. This file evolves; treat it as directional, not immutable.

- **`vectis-summary.md`** — short backbone (~1,000 words). Conversational reference for quick orientation. Same structure as the long doc, compressed. Use this when you need the spine without the depth.

## The research foundation — point-in-time scans

- **`research-1-ai-implementation-landscape.md`** — competitive analysis of ~30 AI implementation firms globally. Use this when working on: positioning, hero copy, voice patterns, pricing architecture, founder-visibility decisions, white-space identification, category map references.

- **`research-2-premium-coaching-landscape.md`** — premium 1:1 AI coaching market scan + 10-category B2B referral partner playbook. Use this when working on: Vectis Residency packaging, Residency pricing, voice for the upskilling line, referral partner outreach (Tal conversation, fractional CFOs, coaches, accountants), B2B partnership economics.

- **`research-3-visual-gravity-scan.md`** — design references (15 aspiration sites + 4 anti-references) and pre-launch build checklist. Use this when working on: site build, copy laid into layout, type stack decisions, color system, motion language, image treatment, anti-pattern reminders. Has its own checklist section to keep open during build sessions.

## Operator context

- **`about-tzvi.md`** — Tzvi's working profile, voice preferences, capacity, side projects. Provides the lens through which all other files should be read.

- **Brand guide images (Sam's 10-page prelim + Tzvi's one-pager).** Active iteration set. Reference for visual iteration; treat as direction-setting, not final. Earlier explorations (Quiet Authority, Classical Marble) were cut — too Metis-adjacent and too philosophical for the Vectis register.

## How to use this project

1. **Open the long md or summary first** for any new conversation that needs Vectis context.
2. **Pull from research files when the conversation is specifically about that domain** (positioning, partner outreach, visual build) — don't default to dragging all three in.
3. **Update the long md as decisions land.** When pricing tiers lock, when the founder agreement is signed, when site goes live — the long doc reflects the current state of the firm. The research files do not change.
4. **Push back on what's written.** The operating principle inside the spine docs is that everything is directional. Future Claude instances and partners are required to suggest improvements when something here is no longer the best call.
